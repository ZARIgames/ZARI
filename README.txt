МОЙ САЙТ С ИГРАМИ — как пользоваться
====================================

В папке:
  index.html        — сам сайт (в самом верху файла — настройки и список игр)
  games/            — сюда кладёшь файлы игр и APK
  shop-icon.png     — пример картинки-иконки

1) КАК ИЗМЕНИТЬ САЙТ
   Открой index.html в любом текстовом редакторе (хоть в Блокноте).
   Найди блок «НАСТРОЙКИ САЙТА» — там название, логотип, цвета, шрифт,
   тёмная тема, ссылки внизу. Меняй значения в кавычках и сохраняй.

2) КАК ДОБАВИТЬ ИГРУ
   а) Положи файл игры в папку games/ (например games/racing.html).
   б) В index.html в блоке «СПИСОК ИГР» скопируй любой блок {...},
      вставь после запятой и поменяй title, icon, desc, tags, play, html.
   в) Если есть APK — положи его в games/ и впиши путь в поле apk.
      Нет APK — оставь apk:"".

3) КАК ВЫЛОЖИТЬ БЕСПЛАТНО (любой способ)
   • Netlify Drop (самый простой): зайди на app.netlify.com/drop,
     перетащи всю папку — сайт сразу получит ссылку.
   • GitHub Pages: создай репозиторий на github.com, загрузи файлы,
     Settings → Pages → Branch: main → Save. Ссылка: имя.github.io/репозиторий
   • Cloudflare Pages: pages.cloudflare.com → Create → Direct Upload.
   Чтобы обновить сайт — загрузи изменённые файлы так же.

Советы:
  • Игры — это обычные HTML-файлы, они работают без сервера.
  • Файлы APK тяжёлые: на GitHub лимит 100 МБ на файл.
  • Кнопка 🔗 в окне игры копирует прямую ссылку на неё (?game=id).
